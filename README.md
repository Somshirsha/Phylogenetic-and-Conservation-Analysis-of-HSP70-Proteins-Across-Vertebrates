# Phylogenetic and Conservation Analysis of HSP70 Proteins Across Vertebrates

## Overview

This project focuses on comparative genomics and evolutionary analysis of HSP70 protein sequences across vertebrate species using computational bioinformatics workflows. The study integrates sequence alignment, phylogenetic inference, and conservation profiling to investigate evolutionary relationships, conserved functional regions, and mutation hotspots in HSP70 proteins.

The workflow combines sequence retrieval, multiple sequence alignment, phylogenetic tree construction, and conservation analysis using Biopython-based pipelines and comparative genomics approaches.

---

## Research Objectives

* Analyze evolutionary relationships of HSP70 proteins across vertebrate species.
* Perform comparative sequence analysis using phylogenetic methods.
* Identify conserved functional regions in HSP70 protein sequences.
* Detect mutation hotspots and sequence conservation patterns.
* Construct phylogenetic trees for evolutionary inference.

---

## Dataset

## Methodology

### Sequence Retrieval and Preprocessing

* Retrieved HSP70 protein sequences for multiple vertebrate organisms.
* Processed and formatted protein sequence datasets for downstream analysis.

### Multiple Sequence Alignment

* Performed multiple sequence alignment using MUSCLE.
* Evaluated sequence conservation and alignment consistency.

### Phylogenetic Analysis

* Constructed phylogenetic trees for evolutionary relationship analysis.
* Analyzed species divergence and evolutionary clustering patterns.

### Conservation Profiling

* Identified conserved functional domains across aligned protein sequences.
* Investigated mutation hotspots and sequence variability regions.
